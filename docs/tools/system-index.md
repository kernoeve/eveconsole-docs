# System Index

The industry cost indices of the systems you care about: today's figure for every activity in one table, and each activity's history as a chart.

Open it from the left sidebar under **Industry**.

A system's cost index is the share the game charges on top of a job's value for building there, and it moves as more or less industry runs in the system. Use this tool to watch your own systems, or to compare one you might move to. To see what those moves do to the cost of a particular job, use **Compare** in [Indy Parks](../industry-parks.md#comparing-parks).

## Using it

1. Type at least two letters of a system's name in **Add system**.
2. Pick it from the list, which gives each system's region. It joins the table and the charts.
3. Repeat for as many systems as you want. **✕** at the end of a row takes that system off.
4. Click **Refresh** to read the figures again.

The list is remembered on this machine.

## The table

One row per system, in the order added: **System**, **Region**, and today's index as a percentage for **Manufacturing**, **Reaction**, **Invention**, **Copying**, **ME Research** and **TE Research**. A `–` means the app holds no index for that activity in that system.

The figures are the same ones the [Production Calculator](production-calculator.md) costs jobs with.

## The charts

Six charts, three rows of two, one for each activity. Each has a line per system, showing that activity's index for each day. The note above the charts gives the dates covered.

- **The dot beside a system in the table is its colour in every chart.** That is the charts' only legend.
- Removing a system doesn't repaint the others. The next one you add takes the free colour.
- A day with no record for a system is a gap in its line, not a guess.
- The charts draw the first eight systems. The rest stay in the table, with no dot.

!!! note
    History is what the app has recorded from the map statistics since it started keeping them, so a new install starts with a short line that grows by the day. A system with no record reads *No history for these systems in this activity yet*.

## Posting it

The [Scheduler](scheduler.md) has a **System Index** section that posts today's table and any of the six charts to Discord or Slack on a schedule. The section keeps its own list of systems, so changing the list here doesn't change the post.
